E7 Bird Neural Network Reproduction
==================================

CPU reproduction of the original resource744 bird neural network, with original
model weights, biases and command order. Physical validation was performed on
Nikon ZR C1.10; the corresponding Z9 resource744 model body is byte-identical.

This privacy-reviewed English edition includes two procedural physical regression
fixtures. Their full input bytes are independently regenerated by
experiments/generate_inputs.py. Photographic inputs, desktop screenshots,
natural-image activation dumps and device-session buffers are not distributed.

Quick start (Windows x64, Python 3.11; inside this directory)
  py -3.11 -m venv ..\e7-env

For an offline release archive:
  ..\e7-env\Scripts\python.exe -m pip install --no-index --find-links .\wheelhouse --require-hashes -r .\requirements-lock.txt
For a source checkout:
  ..\e7-env\Scripts\python.exe -m pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu

Check and run:
  ..\e7-env\Scripts\python.exe -B verify_integrity.py
  ..\e7-env\Scripts\python.exe -B -X utf8 verify.py --case all --output ..\e7-verification
  ..\e7-env\Scripts\python.exe -B -X utf8 run.py fixtures\stripe\input-chw-u8.bin --planar-u8 --output ..\e7-stripe-result

Output directories must be new and outside the package. Add --heads-only to omit
the optional Windows candidate-decoder DLL. Standard image input uses Pillow RGB
conversion and a bilinear stretch to 384x256. Exact planar input is 294912 bytes
of u8 CHW[3,256,384], divided by 256 inside the network.

Outputs: fine[22,16,24] and coarse[33,8,12], stored as uint16 half bit patterns.
Compare bits to retain signed zero. The optional raw candidate decoder does not
perform autofocus selection or tracking. No camera or chip SDK is needed.

docs/ documents arithmetic and evidence boundaries. experiments/ provides
procedural input regeneration, an evidence checker and numerical counterfactuals.
The standalone experiments release archive contains the same research scripts
and only the reviewed synthetic tensor evidence. Validation reports identify
which results can be rerun from public fixtures and which are historical summaries.

Private chip documents, courses, SDKs, toolkits and vendor tools are excluded.
No firmware images, firmware instruction dumps, original debug framework,
credentials, machine identifiers, personal paths or device-session receipts are
included. Only the original network-specific model assets are retained.
