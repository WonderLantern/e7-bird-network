Evidence and redaction boundary
===============================

Public inputs:
  stripe: value(c,y,x) = (x + 3*y + 71*c) modulo 256.
  random: NumPy default_rng(20261018), integers(0,256,(3,256,384),uint8).
The generated bytes must exactly match the physical regression input hashes.
They contain no photographs, desktop content or device-session state.

Expected logical heads and defined final-writer work values come from controlled
original-network replay. Only defined work positions are retained; uninitialized
or unrelated memory, raw inference parameters and runtime pointers are excluded.
The source numerical core and original model body retain their original hashes.

Earlier local tests also covered six photographic inputs, including three live
natural-frame associations. Their input pixels, heads, intermediate values,
detector buffers and device-session metadata are not public. Only aggregate
comparison counts and arithmetic-variant metrics are retained.

A failed structural live association was explicitly rejected rather than counted
as a hardware arithmetic failure. Public acceptance uses the two synthetic
physical fixtures and does not rely on the rejected association.
